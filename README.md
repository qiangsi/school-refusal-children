# 厌学儿童 · AI 游戏创作营活动设计方案（教师备课库）

> **命名说明**：本仓库名称是给教师检索、归档用的**内部项目词**，不是对学生的称呼。所有学生与家长可见的材料（活动页、报名表、证书、公示、反馈单）一律不出现「厌学」等身份标签，不筛查、不鉴定、不依据成绩或考勤筛选。

这里存放「重启好奇心 · 毛豆杯 AI 游戏创作营」背后的完整教学设计，供备课、校内评审、家长沟通与跨校复用。对外的活动页在另一个仓库：[maodou-cup-ai-game-camp](https://github.com/qiangsi/maodou-cup-ai-game-camp)。

| 文件 | 内容 |
| --- | --- |
| `活动方案.md` | 目标—活动—评价一致的完整方案：对象、赛题、8 周赛程、支架、量规、伦理边界、FAQ、待确认项 |
| `评价量规.csv` | 100 分过程性评价量规，可直接导入表格工具 |
| `index.html` | 活动页副本，便于离线对照阅读（内容与对外页一致） |
| `assets/maodou-cup-logo.svg` | 活动像素 logo |

## 为什么公开页面换了说法

把一群孩子称作「厌学儿童」并印在活动页上，容易变成二次标签化；再把游戏当作「只要来参加就给你玩」的奖励，也容易变成新的诱饵。因此对外统一用「重启好奇心 · AI 游戏创作营」「暂时对课堂提不起劲的同学」，把**描述处境**和**定义人**分开。内部备课材料保留该检索词，仅为便于教师查找资料，不代表给学生建档或鉴定。

## 目标—活动—评价一致性

| 目标 | 对应活动 | 对应评价 |
| --- | --- | --- |
| 自主与胜任 | 四选一/自拟赛题、允许降难度与换题 | 完成奖、真实表达 25 分 |
| 表达与叙事 | 把日常困惑写进规则与关卡 | 真实表达 25 分、创意可玩 25 分 |
| 计算思维与 AI 素养 | 任务卡拆小、AI 使用三问、V1→V2 迭代 | 迭代证据 25 分、AI 透明与安全 10 分 |
| 协作与反思 | 2—4 人角色自选、试玩互评、一句话复盘 | 协作与反思 15 分 |

## 使用边界

- 这是设计草稿，是否符合本校/本班实际需教师审核确认；学段默认初中 7—9 年级，可按校情调整。
- 活动是教育支持性活动，**不是心理诊断或干预**，不替代学校心理健康工作，不承诺提升成绩。
- 若出现明显情绪困扰，由班主任与心理教师按学校既有流程跟进。
- 页面中的报名表为前端演示，不采集任何数据。
